# Loan-Approval-Prediction
Developed a Loan Approval Prediction project using Python and the Decision Tree Classification Algorithm. Created the application using Streamlit, Pandas, and CSV. Users can enter their own income details, and the model predicts whether the loan is approved or not. The application runs through a local web interface.
#Working of the Project 
This project predicts loan approval using the Decision Tree Classification Algorithm. Users can enter their own income details instead of using predefined input data. After entering the required income amount and clicking the Predict button, the application processes the input using the Decision Tree model and displays the result as either Loan Approved or Loan Not Approved.
#Technologies Used
Python, Decision Tree Algorithm, Streamlit, Pandas, CSV and Visual Studio Code.
